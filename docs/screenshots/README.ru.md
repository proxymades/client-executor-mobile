# Список скриншотов приложения

[English](README.md) | [Русский](README.ru.md)

Снимайте настоящее приложение с демонстрационными аккаунтами сервера. Не используйте реальные имена, телефоны, фотографии заказчиков или push-сообщения.

Нужные кадры:

1. Создание заказа заказчиком, включая категорию и город.
2. Лента исполнителя и фильтры.
3. Детали заказа и предложение цены.
4. Сравнение предложений и выбор исполнителя заказчиком.
5. Завершённый заказ и отзыв.
6. Профиль и тёмная тема.

Запишите платформу, устройство или симулятор, версию ОС и дату. Добавьте PNG-файлы сюда и вставьте их в README на обоих языках после нативного запуска. Скриншоты пока не получены.
